# HarbourMaster v1.5.0

**Created by RaccoonCloud** for the Harbour Masters team and community.

## What's new
- **Game update notifications** — yellow banner and Update button when installed ports have a newer HarbourMasters release
- **Launcher self-update** — checks HM-Launcher releases, notifies you, and can update HarbourMaster.exe from inside the app
- Settings: toggle launcher update checks + manual “Check for launcher update”
- Version shown as v1.5.0 in the window title and Settings

## Install
1. Download `HMLauncher-v1.5.0.zip`
2. Extract it
3. Run `HarbourMaster.exe`

Use your own legally obtained ROMs / games. Do not share or distribute ROMs.

## Notes
- Game updates still come from HarbourMasters GitHub repos
- Launcher updates come from this project's GitHub Releases
- For self-update to work for others, release downloads must be reachable (public repo/releases recommended)
