# ShipYard v1.9.0

**Created by RaccoonCloud** for the Harbour Masters team and community.

## What's new
- **Renamed to ShipYard** (was HarbourMaster) so it’s clearer this is a community launcher, not Harbour Masters itself
- Same features as 1.8: per-game Install / Update / What’s new, installed vs latest versions, footer Update Launcher
- First launch still won’t auto-download every game it finds on disk

## Install
1. Download `ShipYard-v1.9.0.zip`
2. Extract it
3. Run `ShipYard.exe`

Use your own legally obtained ROMs / games. Do not share or distribute ROMs.

## Notes
- Game updates still come from HarbourMasters GitHub repos
- Launcher updates come from this project's GitHub Releases
- If you used HarbourMaster before: extract ShipYard fresh (or next to the old folder) — your library path in Settings can stay the same
