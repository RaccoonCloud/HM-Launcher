# HarbourMaster v1.0.0

First public release of HarbourMaster — Windows launcher for Harbour Masters PC ports.

**Created by RaccoonCloud** for the Harbour Masters team and community.

## In this release
- Install / update / launch Harbour Masters ports from GitHub
- Library folder + settings
- Auto-update option for game builds
- Archipelago SoH apworld helper
- Discord link
- Ready-to-run Windows EXE (no Python required)

## Install
1. Download `HMLauncher.zip` below
2. Extract it
3. Run `HarbourMaster.exe`

Use your own legally obtained ROMs / games. Do not share or distribute ROMs.

## What's next
Future improvements and additions are planned (launcher self-update, UI polish, more helpers, and new ports as they ship). This v1.0.0 baseline is solid for daily use now.
