# HarbourMaster v1.8.0

**Created by RaccoonCloud** for the Harbour Masters team and community.

## What's new
- **Installed + latest version** shown on every game card
- Clear yellow **Update** button per game when a newer HarbourMasters build is available
- **What's new** — read that release’s changelog (GitHub release body) in the launcher
- Footer shows **HarbourMaster v1.8.0** and an **Update Launcher** button

## Install
1. Download `HMLauncher-v1.8.0.zip`
2. Extract it
3. Run `HarbourMaster.exe`

Use your own legally obtained ROMs / games. Do not share or distribute ROMs.

## Notes
- Game updates still come from HarbourMasters GitHub repos
- Launcher updates come from this project's GitHub Releases
- For self-update to work for others, release downloads must be reachable (public repo/releases recommended)
